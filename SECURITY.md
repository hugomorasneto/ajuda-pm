# Como relatar um problema de segurança

Envie o relato em privado para [contato@techtupa.com.br](mailto:contato@techtupa.com.br). Informe a revisão ou URL afetada, o impacto observado e os passos para reproduzir em um ambiente autorizado, usando dados fictícios. Se houver uma credencial exposta, indique o caminho do arquivo e a revisão sem copiar o valor. Preserve dados pessoais e tokens no ambiente de origem.

Use as issues públicas para falhas comuns. Combine a divulgação de um problema de segurança com o mantenedor depois da avaliação.
